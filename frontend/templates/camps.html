Donation camps

Anyone signed in as a donor, staff or admin account can view camps. Only active staff and admin accounts can create or change them; the server checks this on every request. Cancelling a camp cancels every confirmed appointment in it and queues one notification per donor (mock delivery only in this demo; a message already being sent cannot be recalled). Donors never see cancelled camps, even if they filter for them.
