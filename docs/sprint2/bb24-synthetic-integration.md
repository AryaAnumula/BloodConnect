Download/extract PR62's dataset and manifest into a separate folder or use its local checkout. From this story checkout in PowerShell:

```powershell
$env:DJANGO_DEBUG = '1'
$env:BLOODCONNECT_REPORT_SOURCE = 'synthetic'
$env:BLOODCONNECT_DEMO_DATASET_PATH = (Resolve-Path '../BloodConnect-Synthetic-Data/datasets/synthetic/bloodconnect-demo-v1/dataset.json').Path

```
