## Branches
Use existing member branches or story/<member>-bbNN from latest main after foundation approval. One story per commit; small PRs reviewed/merged by Arya. When a member branch already has open PR, agree separate story branch or update scoped PR; never mix unrelated implementation invisibly.
Synchronize by MERGE, not rebase/force push: git fetch origin; git merge origin/main on clean branch. A fork uses upstream for shared main, origin for own push. If conflicts, inspect and preserve all relevant tests/decisions. Do not accept one whole side blindly.
