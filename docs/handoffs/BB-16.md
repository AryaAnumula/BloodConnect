## Implemented

- **`IssueRecord`** (`blood_requests/models/issue.py`, migration `0003_issuerecord`):
  - UUID id; `request` FK PROTECT; `unit` **OneToOne** to `inventory.BloodUnit`, PROTECT (one issue per unit, enforced by the DB); `issued_by` FK PROTECT
  - aware `issued_at`; `issued_quantity` with CHECK `= 1`; index on `issued_at`
- **`POST /api/v1/requests/<uuid:request_id>/issues`** → 201 IssueResponse. Active non-superuser STAFF, session + CSRF, strict body `{"unit_ids": [...]}` (1–100 canonical UUIDs, no duplicates).
- **`issue_request`**, in one caller-owned transaction:
  1. lock the request `FOR NO KEY UPDATE`; recheck APPROVED (422 `invalid_transition`)
  2. reject oversupply (422 `oversupply`)
  3. real `allocate_units` locks the units in UUID order, rechecks status, expiry (Asia/Kolkata date, taken after the locks; `today >= expiry` is unsafe), group and component, and marks them ISSUED inside a savepoint
  4. verify the DTOs exactly; write one IssueRecord per unit
  5. `fulfilled_quantity += n`; exact completion becomes ISSUED

  Any failure rolls everything back.
- **Errors:** her `inventory.exceptions.UnitConflict` (409) and `UnsafeUnit` (422) are DRF exceptions with the same codes, so they pass through unchanged. Unknown units → 404 (hers). `IntegrityError` → 409 `unit_conflict`; other `DatabaseError` → 503 `storage_unavailable`. A missing inventory module → 503 `inventory_unavailable`. Anything else is re-raised, never swallowed.
- **`request_issue_totals(*, start=None, end=None)`** → `{"issued_unit_count": int}`:
  - sums real `IssueRecord.issued_quantity`
  - both bounds None means all history; otherwise aware datetimes with `start < end`, over the half-open interval `[start, end)`
  - invalid bounds raise `ValidationError`; storage errors propagate (reporting shows "unavailable", never a fake 0)
  - Arya's BB-24 provider `reporting.providers.activity.issue_totals` reads it correctly (verified in the lane)
- **Staff UI** (`/staff/requests`, Approved filter): "Issued X of Y" and an **Issue units** control. Plain "Nothing was issued" messages for `unsafe_unit`, `not_found`, `unit_conflict`, `oversupply`, `invalid_transition` and `inventory_unavailable`; server text is rendered as text only.
